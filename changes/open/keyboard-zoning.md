# Keyboard Zoning

**Mode:** Formal

## Intent

Rearrange bindings so the keyboard zones read naturally, now that the help overlay shows the full board. Seed idea: move the 32b and 64b jumps one key left (Shift+4/5 → Shift+3/4, Shift+R/T → Shift+E/R), freeing the Shift cells of the 5/T column. (The bare layer still carries the ±16b jumps there — a fully free buffer column would need those to shuffle too, or the zoning to accept a partial gap.) A subtle visual separator in the help overlay (subtler than the removed `┆`) may then mark the zone boundary — or the empty column may be separation enough. (2026-08-25)
