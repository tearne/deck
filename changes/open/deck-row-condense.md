# Deck Row Condense

**Mode:** Formal

*(Spun out during message-stream planning. Best taken after [message-stream](message-stream.md) lands.)*

## Intent

Once the message stream routes all passive messages to the global bar, each deck's notification row carries only the track title, playlist badge, `[BPM][Tick][Cue]` indicators, and the deck-attached prompts (BPM confirmation, rename offer). Review whether the row still earns its screen line — the suspicion is things can be condensed, e.g. by removing the BPM/Tick/Cue indicators.
