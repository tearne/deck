# Key Hint Overload

**Mode:** Formal

## Intent

The footer rows are overloaded with key hints — mode legends, pane hints, and status suffixes (e.g. the workspace hint) all compete for one line each, and important signals get lost in the noise. Consider replacing the always-on hints at the bottom with some kind of help overlay, summoned on demand, so the footers can carry only state. (2026-09-02, spun out of bottom-pane-ui-review testing.)
