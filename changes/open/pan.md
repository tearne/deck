# Pan

## Intent
Each deck has no stereo positioning control. This change adds per-deck panning so the operator can place decks in the stereo field during a mix.

Pan is controlled directly per deck via fixed key columns (not via the selected deck model), consistent with how level, gain, and filter are handled in the mixer section.

Note from overview-corners (2026-08-12): pan's readout should join the meters segment of the overview's top-right readout line (level/gain/PFL) when built.
