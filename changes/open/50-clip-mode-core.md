# Clip Mode Core

**Mode:** Formal

*(Part of the loop-rethink sequence — see the design for ordering and context.)*

## Intent

The new third mode: the track sliced into start points aligned to the beat grid, each paired with an end slice (not necessarily adjacent). Clips loop, run on, or are jumped between with phase-preserving arithmetic (rules to be settled by prototyping within this change). Slices mark both waveforms like beat triangles; overlays show the active clip, its loop state, and what comes next; boundaries get the prototype's crossfade, possibly configurable. Beat-jump keys repurpose as clip jumps in this mode.
