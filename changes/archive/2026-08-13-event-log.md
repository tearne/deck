# Event Log

**Mode:** Formal

*(Spun out during message-log-file planning. Best taken after it lands.)*

## Intent

Messages today are notices, warnings and errors — things that interrupt. Expand the remit to routine events, such as which track was loaded on which deck, so the log reads as a session narrative rather than only its problems. Needs a design decision on visibility: routine events probably belong in the log and history view without occupying the global bar on every occurrence.

Rider agreed during map catch-up: rename the recorded kind from "message" to "event" in code (`Message` type, `messages` module naming) to match the map's prompts/events/hints vocabulary.

## Approach

### Recorded, not displayed

The stream gains a second entry path: `record()` appends to the in-memory log and the file exactly like `emit()`, but never touches the bar. Interrupting events keep `emit()`; routine events `record()`. The history view and log file need no changes — they already show whatever the log holds.

### First routine events

Two to start: **track-load completion** ("loaded <name>", deck-sourced; name alone, no set position — one event site covers browser loads, panel loads, and playlist advance, since all funnel through load completion) and **clean quit**, closing the bracket the started line opens, so a session reads start-to-quit. Further events accrue by demand — each is a one-liner once the path exists.

### The rename

Type `Message` → `Event`; `MessageStream` → `EventStream`. The module stays `messages` and the file stays `messages.log` — both name the umbrella concept (prompts/events/hints) as the map's Messages node does, while the recorded kind is an event.

### Map

The Messages node's Events bullet gains the log-only nuance (not every event occupies the bar) — post-build catch-up.

## Plan

- "deck quit" records on all three quit paths — quit-confirm, direct quit, and Ctrl-C.

- The "deck v… started" line stays a displayed emit rather than a record — it doubles as on-bar version confirmation at launch.
